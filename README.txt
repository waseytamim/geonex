GeoNexa Personal Edition 1.0

HOW TO OPEN
1. Extract the GeoNexa folder from the ZIP file.
2. Open the folder.
3. Double-click index.html. It opens in Chrome or Edge.
4. Use the left navigation to explore the workspace.

DATA & PRIVACY
This is a local first-version prototype. Notes, tasks, journal entries, project ideas and progress are saved in the browser's localStorage on this device/browser profile.
It does NOT provide secure account login, cloud sync, encrypted storage, or a hosted private website.
Do not store passwords, sensitive personal information or confidential research data.
Use Settings & Backup to export a JSON backup regularly.

NOTES
- The Resource Library links to external official resources.
- The curriculum is a starter learning roadmap; it is not an accredited course.
- Project cards are ideas/placeholders, not completed research results.
- Internet is needed for Google Fonts and external resource links; the core app runs locally.
